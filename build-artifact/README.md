# Upload Magento Build Artifact (`build-artifact`)

Uploads all `.tgz` and `.gz` files inside the build's artifact output directory (generated by `build-dump` and any custom export steps) as a GitHub Actions workflow artifact with `compressionLevel: 0` (since the archives are already gzip-compressed).

## Usage

### Upload Using the Build Name from `build-init`

```yaml
      - name: Upload Magento Data Artifact
        id: artifact
        uses: ecomdev/action-build-magento-data-artifact/build-artifact@v2.0.0
        with:
          config-file: ${{ steps.init.outputs.config-file }}

      - name: Download Artifact
        uses: actions/download-artifact@v8
        with:
          artifact-ids: ${{ steps.artifact.outputs.artifact-id }}
          path: ./magento-data
```

### Upload Using a Custom Artifact Name

```yaml
      - name: Upload Custom Named Artifact
        id: artifact
        uses: ecomdev/action-build-magento-data-artifact/build-artifact@v2.0.0
        with:
          config-file: ${{ steps.init.outputs.config-file }}
          name: magento-2.4.9-b2b-fixture
```

## Inputs

| Input | Required | Default | Description |
| --- | :---: | --- | --- |
| `config-file` | **Yes** | — | Path to the build configuration file exported by `build-init` (`steps.<init-id>.outputs.config-file`). |
| `name` | No | `''` | Custom GitHub Actions artifact name. If omitted, defaults to the `name` configured in `build-init`. Note that artifact names must be unique within a single workflow run. |

## Outputs

| Output | Description |
| --- | --- |
| `artifact-id` | ID of the uploaded GitHub Actions data artifact. |
| `artifact-digest` | SHA-256 digest of the uploaded GitHub Actions data artifact. |
